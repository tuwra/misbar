# مِسبار | منصة التعلّم الذكية

منصة عامة: يرفع الطالب درسه (PDF أو صور أو Word أو PowerPoint أو نص)، فتقرؤه المنصة وتبني منه شرحًا تفاعليًا ومختبرًا واختبارات وبطاقات وخريطة مفاهيم وخطة مراجعة. تعمل لكل المواد، مع أدوات خاصة للفيزياء والكيمياء والرياضيات والتاريخ.

لا يحتاج الطالب أي حساب. الذكاء الاصطناعي يعمل من خادم المنصة عبر **Google Gemini** (له طبقة مجانية)، والمفتاح محفوظ في الخادم ولا يصل إلى المتصفح أبدًا. ويمكن بدلًا منه استخدام Claude من Anthropic (مدفوع).

## ما الجاهز في المنصة

- **تسجيل دخول** باسم مستخدم وكلمة مرور. الحسابات يضيفها المشرف فقط، ولكل مستخدم مكتبته الخاصة على جهازه.
- **درس «الآلات» الجاهز** (فيزياء ثاني ثانوي، الفصل 4-2، ص 109–117) يظهر في مكتبة كل مستخدم تلقائيًا، ويعمل كاملًا حتى بدون ذكاء اصطناعي:
  - شرح ثلاثي الأبعاد بخمسة مشاهد: الرافعة، والبكرات، والعجلة والمحور، والمستوى المائل، والدراجة كآلة مركبة. فيه لوحات بيانات حيّة، وجولة شرح بالكاميرا، ومتغيرات تتحكم بها.
  - شرح لكل قسم من الأقسام السبعة بثلاثة مستويات، مع أسئلة تحقق وأمثلة محلولة.
  - 37 سؤالًا جاهزًا (اختيار، صح وخطأ، مسائل تُحسب برمجيًا، قراءة رسوم).
  - مسائل الكتاب (24–33 ومسألة التحفيز) محلولة خطوة بخطوة.
  - ملخص بثلاثة مستويات، وخريطة مفاهيم، وبطاقات، وظواهر للتفسير، وخمس تجارب في المختبر، وصفحات الكتاب نفسها.
- تحتاج للذكاء الاصطناعي فقط الأدوات التي تكتب محتوى جديدًا: المساعد، وأسئلة جديدة، وحل مسألة تكتبها أنت، والدروس التي ترفعها.

## الحسابات (تسجيل الدخول)

- أنشئ لكل شخص سطرًا بهذا الأمر:
  ```bash
  npm run add-user -- اسم_المستخدم كلمة_المرور
  ```
- ضع الأسطر في المتغير `MISBAR_USERS` مفصولة بـ `;`، وضع نصًا عشوائيًا طويلًا في `MISBAR_SECRET`.
- إذا كان `MISBAR_USERS` فارغًا تفتح المنصة بدون تسجيل دخول.
- كلمات المرور لا تُحفظ نصًا؛ يُحفظ منها بصمة مشفرة (scrypt) فقط.
- عند النشر على Vercel انسخ `MISBAR_USERS` و `MISBAR_SECRET` إلى Environment Variables.

## مكونات المشروع

| المسار | الوظيفة |
|---|---|
| `public/` | الواجهة كاملة (HTML وJS، بدون خطوة بناء) |
| `lib/ai-handler.mjs` | نقطة الذكاء الاصطناعي: تستقبل الطلب، وتستدعي Claude، وتنفّذ الحسابات بمكتبة math.js، وتطبّق حدود الاستخدام |
| `api/ai.js` و `api/login.js` | دوال Vercel للذكاء الاصطناعي وتسجيل الدخول |
| `lib/auth.mjs` | الحسابات وجلسات الدخول |
| `public/scene3d.js` | الشرح ثلاثي الأبعاد (Three.js) |
| `public/builtin/machines.js` | محتوى درس «الآلات» الجاهز وصور صفحاته |
| `server.mjs` | خادم محلي للتشغيل على جهازك |

## التشغيل على جهازك

1. ثبّت Node.js 18 أو أحدث.
2. داخل مجلد المشروع:
   ```bash
   npm install
   ```
3. احصل على مفتاح Gemini مجاني: ادخل aistudio.google.com بحساب Google، ثم **Get API key ← Create API key**.
4. انسخ `.env.example` إلى ملف جديد اسمه `.env`، وضع فيه المفتاح:
   ```
   GEMINI_API_KEY=...
   ```
5. شغّل المنصة:
   ```bash
   npm start
   ```
   ثم افتح http://localhost:3000

## النشر للعامة (Vercel)

1. ارفع المجلد إلى مستودع على GitHub. ملف `.env` مستثنى تلقائيًا، فلا يُرفع المفتاح.
2. في vercel.com: **Add New → Project**، واختر المستودع.
3. في **Environment Variables** أضف `GEMINI_API_KEY` بقيمة مفتاحك، ثم **Deploy**.
4. ستحصل على رابط عام مثل `misbar.vercel.app`، ويمكنك ربطه بنطاقك.

## المجانية وحدودها

- **الطبقة المجانية في Gemini** لا تحتاج بطاقة، لكن لها حدّ لعدد الطلبات في الدقيقة واليوم لكل مشروع (تراه في aistudio.google.com/rate-limit). إذا وصلت المنصة الحد، يرى الطالب رسالة «انتظر ثم أعد المحاولة»، ويتجدد الحد يوميًا.
- **شرط مهم:** في الطبقة المجانية تستخدم Google المحتوى المرسل لتحسين منتجاتها. لا ترسل عبرها بيانات شخصية حساسة. إذا كبرت المنصة، فعّل الفوترة في المشروع نفسه وتختفي هذه النقطة وترتفع الحدود.
- الأدوات التي لا تحتاج الذكاء الاصطناعي (المختبر، البطاقات، راسم الدوال، الخرائط المحفوظة) تعمل دائمًا ولا تستهلك أي حصة.

## متغيرات اختيارية

| المتغير | الأثر |
|---|---|
| `MISBAR_MODEL` | النموذج. الافتراضي مع Gemini هو `gemini-3.8-flash`. البديل الأخف `gemini-3.5-flash-lite` (أسرع وحصته أوسع عادةً، لكنه أضعف في تحليل الدروس) |
| `MISBAR_FALLBACK_MODEL` | النموذج البديل الذي تتحول له المنصة تلقائيًا إذا خلصت حصة النموذج الأساسي. الافتراضي `gemini-3.5-flash-lite` (حصته اليومية أكبر). ضعه فارغًا لإيقاف التحويل |
| `AI_PROVIDER` | `gemini` أو `anthropic`. لاستخدام Claude ضع `ANTHROPIC_API_KEY` (مدفوع حسب الاستهلاك) |
| `MISBAR_ACCESS_CODE` | إذا وضعت رمزًا، لا يستخدم الذكاء الاصطناعي إلا من يعرفه، فتبقى الحصة لطلابك |
| `MISBAR_RATE_LIMIT` | عدد الطلبات المسموح لكل زائر كل 10 دقائق (الافتراضي 60)، حتى لا يستهلك شخص واحد الحصة كلها |

ملاحظة: حدّ الطلبات لكل زائر يُحفظ في ذاكرة الخادم ويُصفَّر عند كل تشغيل جديد للدالة على Vercel. إذا كبرت المنصة، اربطه بقاعدة بيانات مثل Upstash Redis.

## أين تُحفظ دروس الطلاب؟

في متصفح جهاز الطالب نفسه (IndexedDB)، بلا حسابات ولا خادم. من صفحة المكتبة يستطيع الطالب **تصدير دروسي** إلى ملف واستيراده على جهاز آخر. إذا احتجت لاحقًا حسابات ومزامنة بين الأجهزة، فالخطوة التالية ربط المنصة بقاعدة بيانات مثل Supabase.

## ملاحظات تقنية

- قراءة صفحات الكتاب تتم بالرؤية (الصور تُرسل للنموذج) لأن نص ملفات PDF العربية يخرج مبعثرًا غالبًا.
- كل الأرقام في حل المسائل والاختبارات تُحسب برمجيًا (math.js) ويُتحقق منها، ولا يُعتمد على حساب النموذج وحده.
- مع Gemini يُعاد التحقق من الأرقام في المتصفح بمكتبة math.js. ومع Claude تُستخدم أيضًا أداة حاسبة على الخادم أثناء الحل، ويُفعَّل خيار الاحتياط (`fallbacks: "default"`) الذي يعيد الطلب على نموذج بديل إذا رُفض بسبب فلاتر الأمان.
